All reviewed files use a similar style-reference structure:

- Theme summary.
- Color tokens with roles.
- Typography tokens and type scale.
- Spacing, shape, radius, and layout tokens.
- Component descriptions.
- Do and don't guidance.
- Surface and elevation models.
- Imagery language.

This skill converts that shared structure into a general workflow: visual direction, tokens, layout, components, interaction, responsive/accessibility, implementation, and quality rubric.

## Product-Focus Hardware Abstractions

Useful abstractions:

- High contrast can create product focus.
- Depth can be surface-based instead of shadow-based.
- A restrained neutral palette can be made actionable with one precise accent.
- Large product visuals and clean type can carry a page without many decorative elements.

Do not copy:

- Exact color palette.
- Source-specific typography.
- Source-like product page composition unless requested.

## Luxury Product Abstractions

Useful abstractions:

- Luxury can come from negative space, material focus, and few soft elements.
- A single deep anchor color can create premium atmosphere.
- Sparse UI can feel intentional when typography and imagery are strong.

Do not copy:

- Source-specific rules.
- Exact indigo/cream palette.
- Product-gallery structure for unrelated pages.

## Approachable Database/Productivity Abstractions

Useful abstractions:

- Complex tools can feel approachable through warm canvas colors, rounded components, and controlled accent palettes.
- Colorful accents work best when used for categories, illustration, or emphasis rather than core text.
- Product screenshots can anchor abstract workflow messaging.

Do not copy:

- Exact accent palette.
- Source-like workflow metaphors unless appropriate.

## Playful Work-Management Abstractions

Useful abstractions:

- Playful productivity can use bright cards, pill controls, and energetic spacing.
- Color variety must encode categories or emphasis.
- Large rounded controls soften structured grids.

Do not copy:

- Violet as the default action color.
- Overly colorful cards for serious or dense interfaces.

## Document/Workspace Product Abstractions

Useful abstractions:

- Dark interfaces need careful surface hierarchy and readable muted text.
- Vivid accents should be restrained and functional.
- UI screenshots on light surfaces can create strong contrast against dark backgrounds.

Do not copy:

- Exact dark navy palette.
- Source-specific font hierarchy.
- Dark mode for every technical product by default.

## Collaboration Product Abstractions

Useful abstractions:

- Expressive collaboration pages can combine clean surfaces with a strong brand color and atmospheric gradients.
- Distinct display typography can create personality while body text stays practical.
- Decorative gradients should be limited to hero or brand moments.

Do not copy:

- The source brand's purple palette.
- Brand-specific typography.
- Gradients that overpower content.
