LedgerLens / 种子轮 Pitch

财务汇报 deck 应该自己更新。

LedgerLens 把数仓指标变成可审计的董事会幻灯片：数字有来源，叙事可检查，证据可刷新。

证据地图：合成试点数据集，12 个财务团队，2026 年 1-4 月。所有指标均为 skill 测试示意。

瓶颈不是图表好不好看，而是对数、解释波动，并证明每一个指标从哪里来。

产品

幻灯片本身变成审计界面。

01 结论

每页先说明它支持哪个决策。

02 Query ID

指标指向已审批后端查询，而不是裸 SQL。

03 证据

来源说明对董事会和投资人保持可见。

04 刷新

运行时可在权限允许时重新注入数据。

来源：ledgerlens.runtime_spec。设计假设：query ID 在服务端做权限控制，DOM 中永不暴露裸 SQL。

协议

硬编码数字变成可刷新的证据。

HTML 仍然只负责呈现。认证、缓存和已审批查询执行，都交给真实应用运行时。

<section class="slide"
  data-source="warehouse.revenue"
  data-query-id="net_revenue_yoy"
  data-metric="enterprise_arr"
  data-stale-after="24h">
  <h1>$4.8M ARR</h1>
</section>

协议说明：query-id 和 metric-id 是安全句柄；裸 SQL 与凭证留在服务端。
